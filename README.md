## Projet à découvrir

### KAYOS CLOUD — galerie photo

Une galerie web qui présente six photos hébergées sur Cloudinary. Le site propose une mise en page adaptée aux différents écrans, des filtres et une recherche pour parcourir les images.

- **Ouvrir la galerie :** [KAYOS CLOUD](index.html)
- **Voir le README du projet :** [Explications et fonctionnement](README.md)
- **Technologies :** HTML, CSS, JavaScript et Cloudinary

Ce projet m’a permis de mettre en pratique la création d’une page web complète et l’affichage d’images depuis un service cloud.
